# AEGEE-Enschede Lustrum VIII Website

Static promotional website for AEGEE-Enschede Lustrum VIII, themed around
clickbait and pixel-era web chaos.

## Local preview

Open `index.html` directly in a browser.

## GitHub Pages

This repository includes a GitHub Actions workflow that publishes the static
site to GitHub Pages.

After pushing this repository to GitHub:

1. Open the repository on GitHub.
2. Go to **Settings -> Pages**.
3. Set **Source** to **GitHub Actions**.
4. Push to `main`; the site will deploy automatically.
